# Oper (Oper Credits)

> Oper Credits is a Belgium-based fintech providing digital mortgage origination software for banks, lenders, brokers and insurers. The modular Oper Connect platform connects the mortgage value chain, and the Herman AI underwriting agent automates document classification, data extraction, verification and credit-policy application. This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public developer portal and OpenAPI definitions.

## APIs

- [Oper Connect API (OpenAPI 3.0.3)](openapi/oper-api.json): Core REST API — loan requests, clients, offers, financial plans, documents, approvals, JWT/OTP authentication. ~487 operations across 286 paths.
- [Oper Connect Resources API (OpenAPI 3.0.3)](openapi/oper-resources.json): 300+ reference/configuration lookup resources.
- [Oper Connect Metrics API (OpenAPI 3.0.3)](openapi/oper-metrics.json): Operational metrics (certificate expiration).
- [Loan Request Webhook API (OpenAPI 3.1.0)](openapi/oper-loan-request-webhook.json): Versioned (1.0-1.4) webhook payload Oper POSTs to a lender-hosted endpoint.

## Authentication

- Scheme: HTTP bearer, JSON Web Token (JWT). See [authentication profile](authentication/oper-authentication.yml).
- Obtain a token: POST /api/jwt/ ; refresh: POST /api/jwt/refresh/.
- Some tenants require OTP: POST /api/sign-in/otp/ then POST /api/sign-in/verify/.
- Access tokens are short-lived and must be refreshed with the refresh token.

## Conventions

- Pagination: page-number style (page, page_size) with count/next/previous/results envelope.
- Sorting: `ordering` query parameter. Filtering: resource-specific query params.
- No idempotency-key header is documented; error payloads are not modeled in the spec.
- See [conventions](conventions/oper-conventions.yml).
